# أداة اختبار اختراق الشبكات — النسخة المطوّرة

هذه نسخة مطوّرة من مشروعك الأصلي، أضيفت لها لوحة تحكم تعمل من المتصفح. لا تحتاج إلى Visual Studio Code لتشغيلها.


## تشغيل المشروع على Windows باستخدام VS Code

1. ثبّت Python 3.11 أو أحدث من: https://www.python.org/downloads/windows/ — فعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. ثبّت Visual Studio Code من: https://code.visualstudio.com/ ثم افتح مجلد `network-pentest-tool` من **File → Open Folder**. يفضّل تثبيت إضافة **Python** من Microsoft داخل VS Code.
3. افتح الطرفية من **Terminal → New Terminal**.
4. في PowerShell اكتب:

   ```powershell
   .\setup_windows.bat
   ```

   ينشئ هذا الأمر بيئة Python مستقلة ويثبت المكتبات. لا تحتاج إلى تفعيل البيئة يدويًا.
5. بعد اكتمال الإعداد، شغّل:

   ```powershell
   .\run_windows.bat
   ```

6. افتح المتصفح على `http://127.0.0.1:5000`. اترك نافذة الطرفية مفتوحة أثناء استخدام لوحة التحكم، وأوقف الخادم بالضغط على `Ctrl+C`.

**ملاحظة عن Nmap:** ستعمل لوحة التحكم ووضع Demo حتى دون Nmap. لإجراء فحص مباشر للأجهزة الخاصة التي تملكها أو لديك تصريح بفحصها، ثبّت Nmap لويندوز من https://nmap.org/download.html ثم أغلق وافتح VS Code مجددًا حتى يتعرف على PATH.

**إذا ظهر خطأ عن عدم العثور على Python:** أعد تثبيت Python مع تفعيل `Add python.exe to PATH`، ثم أعد فتح VS Code.

## تشغيل المشروع على Kali Linux

1. حمّل ملف ZIP وفك الضغط عنه.
2. افتح مجلد `network-pentest-tool`.
3. افتح Terminal داخل المجلد.
4. نفّذ الأمر التالي:

   ```bash
   chmod +x start.sh setup.sh run.sh
   ./start.sh
   ```

5. بعد اكتمال الإعداد، افتح المتصفح على العنوان:

   `http://127.0.0.1:5000`

إذا لم يكن Nmap مثبتًا، ستعمل عينة العرض التجريبية، لكن الفحص الحقيقي يحتاج إلى تثبيت Nmap بالأمر:

```bash
sudo apt update && sudo apt install -y nmap
```

إذا ظهرت رسالة أن `venv` غير متوفر، نفّذ:

```bash
sudo apt install -y python3-venv
```

ثم شغّل `./start.sh` مرة أخرى.

## ماذا أضافت النسخة؟

- لوحة ويب لعرض نتائج الفحص.
- اكتشاف الأجهزة داخل شبكة مختبر خاصة.
- فحص سريع للمنافذ والتعرّف الخفيف على الخدمات وإصداراتها.
- البحث عن تطابقات CVE المحتملة من قاعدة NVD.
- درجة مخاطر تعليمية من 0 إلى 10 مع توضيح عوامل المخاطر.
- محاكاة مراجعة تعرض خدمات المصادقة؛ لا توجد محاولات تسجيل دخول أو تخمين كلمات مرور.
- توصيات أمنية وتنزيل تقرير JSON.
- وضع Demo ببيانات اصطناعية للعرض دون إرسال أي حركة إلى الشبكة.

## حدود الاستخدام الآمن

- الفحص الحقيقي يقبل فقط `localhost` أو عناوين IPv4 الخاصة.
- اكتشاف الشبكة محدود بحد أقصى 256 عنوانًا في المرة الواحدة.
- لا يوجد استغلال للثغرات ولا تخمين كلمات مرور.
- تطابق CVE بالكلمات المفتاحية ليس دليلًا على انطباق الثغرة؛ يجب التحقق من المنتج والإصدار والإعدادات.
- استخدم الفحص فقط على أجهزة تملكها أو لديك تصريح صريح بفحصها.

## العرض عبر رابط عام

يمكن نشر نسخة عامة بوضع `DEMO_ONLY=1`؛ عندها يتم تعطيل الفحص الحقيقي ويظل وضع Demo متاحًا للزوار. تجهيز الملفات لا ينشئ رابطًا عامًا تلقائيًا؛ إنشاء الرابط يتطلب حساب استضافة وربط المشروع به. لا تنشر نسخة عامة تسمح للزوار بفحص أهداف يحددونها.
