# نشر NETSENTRY كرابط عام — Render

هذه الحزمة مجهّزة لنشر **عرض تجريبي عام فقط**. عند النشر، يفعّل ملف `render.yaml` المتغير `DEMO_ONLY=1`؛ لذلك تُعطّل واجهات الفحص الحقيقي واكتشاف الشبكات على الخادم العام. تبقى عينة Demo وتنزيل تقرير العينة متاحين للزوار.

## ما تحتاجه

- حساب GitHub لحفظ نسخة المشروع في مستودع خاص أو عام.
- حساب Render لربط المستودع ونشره.
- لا ترفع مجلد `.venv` أو `venv` أو ملفات التقارير الشخصية أو أي مفاتيح/كلمات مرور.

## 1) ارفع ملفات المشروع إلى GitHub

1. فك ضغط `NetworkPentestTool_PublicDemo.zip` على جهازك.
2. افتح GitHub وأنشئ مستودعًا جديدًا باسم `netsentry-public-demo`.
3. ارفع **محتويات مجلد `network-pentest-tool`** إلى جذر المستودع، بحيث يظهر `render.yaml` بجانب `web_app.py` و`requirements.txt`، وليس داخل مجلد إضافي.
4. تأكد أن المستودع لا يحتوي على `.env` أو `.venv` أو `venv` أو تقارير حقيقية.

## 2) أنشئ الخدمة في Render

1. افتح https://dashboard.render.com/blueprints/new
2. اربط حساب GitHub إذا طلب Render ذلك.
3. اختر مستودع `netsentry-public-demo` الذي أنشأته.
4. سيقرأ Render ملف `render.yaml` تلقائيًا. راجع الإعدادات ثم أنشئ Blueprint.
5. انتظر اكتمال Build وDeploy داخل لوحة Render.
6. افتح رابط `*.onrender.com` الذي يظهر في صفحة الخدمة.

## 3) تحقق من النشر

- افتح `/health` في نهاية رابط الخدمة؛ يجب أن يرجع JSON بحالة `ok` و`demo_only: true`.
- افتح الصفحة الرئيسية، وتأكد من ظهور شارة `PUBLIC DEMO MODE`.
- اضغط `Load Sample Demo` ثم `Download Report`.
- أزرار Host Discovery وRun Assessment تكون معطلة أو ترفض الطلبات؛ هذا مقصود لحماية الزوار والأنظمة الأخرى.

## ما الذي لا تنشره هذه النسخة؟

لا تتيح الخدمة العامة فحص عناوين يكتبها الزائر، ولا تشغّل Nmap، ولا ترسل حركة مرور إلى أجهزة خارجية. الفحص الحقيقي يبقى محليًا على جهازك داخل مختبر مصرح به. لا تغيّر `DEMO_ONLY` إلى `0` على استضافة عامة.

## ملاحظات خطة Render المجانية

الخدمة المجانية قد تدخل في وضع السكون بعد 15 دقيقة دون طلبات، وقد يستغرق أول فتح بعد السكون قرابة دقيقة. نظام ملفات الخدمة مؤقت، لذلك تقارير Demo المخزنة في الذاكرة مؤقتة وقد تختفي عند إعادة التشغيل أو النشر. هذه القيود مناسبة لرابط عرض جامعي، وليست ضمان تشغيل دائم.

## إذا فشل النشر

افتح تبويب **Events** أو **Logs** في Render وانسخ آخر رسالة خطأ كاملة. لا تنشر مفاتيح سرية أو متغيرات بيئة تحتوي على كلمات مرور عند مشاركة السجل.
